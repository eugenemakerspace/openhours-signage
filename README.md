# openhours-signage
A kiosk-friendly browser-based sign showing EMS open hours and upcoming events

## Set up & Calendar API Key

The data for the listing comes from Google Calendar which needs an API key. The API key gets exported from the config.local.js module. After cloning the repo, copy config.local.js.example to config.local.js and replace the `YOUR_GOOGLE_API_KEY_HERE` with the actual API key you get from your Google Console.
